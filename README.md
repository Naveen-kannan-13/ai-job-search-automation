# AI Job Search Automation

Built using Python, Visual Studio Code, and GitHub Copilot.

## Overview
This project automates job searching workflows by:
- Searching jobs across platforms
- Filtering roles based on resume-match criteria
- Matching job descriptions with skills
- Tracking applications in Excel

## Features
- Job filtering automation
- Resume-job matching
- Excel-based application tracking
- AI-assisted workflow development

## Tools Used
- Python
- GitHub Copilot
- Visual Studio Code
- Excel

## Purpose
Reduce repetitive manual effort involved in searching and tracking job applications.
