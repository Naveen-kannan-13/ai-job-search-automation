# AI Job Search Automation

## Overview

This project is an AI-assisted job search automation workflow built using Python, Visual Studio Code, and GitHub Copilot.

The goal of the project is to reduce repetitive manual effort involved in searching, filtering, and tracking job applications across multiple job platforms.

The workflow helps:
- Search relevant jobs
- Match jobs based on resume skills and keywords
- Track applications in Excel
- Organize job opportunities efficiently

## Features

- Automated job search workflow
- Resume and job description matching
- Keyword-based filtering
- Excel-based application tracking
- AI-assisted development using GitHub Copilot
- Structured job tracking workflow

## Workflow

1. Search job listings from platforms
2. Filter jobs based on:
   - skills
   - experience
   - keywords
3. Match jobs with resume profile
4. Store results in Excel tracker
5. Review and apply manually

## Technologies Used

- Python
- Visual Studio Code
- GitHub Copilot
- Excel
- Pandas

## Project Files

- `run_analyst_search.py` → Runs the workflow
- `job_matcher.py` → Matches jobs with profile criteria
- `application_tracker.py` → Tracks applications in Excel
- `analyst_scraper.py` → Handles job data extraction
